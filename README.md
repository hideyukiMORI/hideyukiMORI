## NeNe Nib — a fast text editor that toggles between ordinary and Vim editing

**[github.com/hideyukiMORI/nene-nib](https://github.com/hideyukiMORI/nene-nib)** · Windows 11 x64 · **Beta — [download v0.1.0-beta.2](https://github.com/hideyukiMORI/nene-nib/releases/tag/v0.1.0-beta.2)** (a 0.6 MB ZIP with `SHA256SUMS`; extract and run `NeNeNib.exe`, no installer and no runtime)

One executable. C++23, plain Win32, Direct2D and DirectWrite — no UI library, no runtime dependency. It edits like Notepad until you flip one switch in the status bar; then it is Vim.

| | |
| --- | --- |
| **Two ways to edit, one toggle** | Ordinary editing (selection, clipboard, undo/redo, mouse) or Vim NORMAL / INSERT / VISUAL — motions, operators, counts, text objects, registers, macros, `.` repeat, blockwise VISUAL, search with highlighting. |
| **A Vim engine written from scratch, checked against real Vim** | **1,853 fixtures generated by Vim 9.1** are replayed in the test suite, plus 78 more for movement in wrapped text. What is not implemented yet is listed in the README, command by command. |
| **Japanese from day one** | IME composition drawn in place; Vim NORMAL turns the IME off and INSERT turns it back on. UTF-8, UTF-8 BOM, and Shift_JIS; CRLF / LF kept as read. |
| **Tabs and Ctrl+P** | Tabs live in the title bar and come back on the next start with caret and scroll position. Ctrl+P fuzzy-finds open tabs, bookmarks, recently closed files, and files in the current folder. Drop files from Explorer to open them. |
| **Look** | Frameless window with a Mica title bar, follows the OS light / dark theme. **95 built-in colour schemes** (`:colorscheme`), plus user themes. Line wrapping, font size on Ctrl + wheel. |
| **Speed, measured** | On the reference machine: startup 191 ms, window visible 35 ms, one keystroke 0.9 ms, a 16 MiB file opens in 250 ms. The benchmark script and reference values are in the repo. |
| **Not yet** | Markdown preview, files above 64 MiB, syntax highlighting, `:s` / `:g`, split windows. No code signing, installer, or auto-update in the beta. |

Every feature is one numbered requirement in [`SPECIFICATION.md`](https://github.com/hideyukiMORI/nene-nib/blob/main/SPECIFICATION.md); the decisions are in [`docs/adr/`](https://github.com/hideyukiMORI/nene-nib/tree/main/docs/adr) and the measurements in [`docs/quality/gate-proofs.md`](https://github.com/hideyukiMORI/nene-nib/blob/main/docs/quality/gate-proofs.md).
